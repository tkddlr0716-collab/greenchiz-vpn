## 시작 순서

1. [사이트 회원가입](https://greenchiz.com/member/signup)에서 이메일 인증과 비밀번호 설정을 마치세요.
2. [NEXT 0.8.1 시험판 ZIP](https://greenchiz.com/download) 전체를 짧은 경로에 풀고 GreenchizNext.exe를 실행하세요.
3. 넥슨 런처를 설치하고 한 번 실행한 뒤 완전히 종료하세요.
4. 그린치즈 계정으로 로그인하고 **앱 추가 → 사용할 앱 여러 개 체크 → 선택한 앱 추가 → 통합 VPN 켜기** 순서로 진행하세요. 넥슨·메이플 전용 연결은 앱의 별도 안내를 따르세요.

넥슨 게임 계정과 그린치즈 계정은 별도입니다. 넥슨 비밀번호를 그린치즈에 입력하지 마세요.
