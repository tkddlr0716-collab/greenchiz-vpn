[서비스 운영자 안내] 글클메 정식 오픈을 준비하는 분께 그린치즈 VPN을 소개합니다.

넥슨 공식 FAQ의 Grand Launch 일정은 한국 시간 2026년 10월 22일(목) 오전 3시입니다. 변경 여부는 공식 공지를 확인해 주세요.

그린치즈는 Windows용 무료 VPN을 테스트 운영하고 있습니다. 현재 기본 다운로드는 게임·브라우저·런처 실행 파일을 선택하는 NEXT 0.8.10 Windows x64 시험판 ZIP입니다. 전체 압축 해제 후 GreenchizNext.exe를 실행합니다. 기존 0.1.38 파일은 이전 버전 링크로 별도 제공합니다.

0.8.10은 연결 지역·VPN 출구 IP·핑을 통합 VPN 위에 표시합니다. 연결 국가는 현재 미국만 제공합니다. 연결 전이나 측정값이 오래된 경우 확인 중으로 표시하며, 핑은 게임 내 지연 시간이 아닌 VPN 중계 시험 응답입니다.

자동 상태 조회 중 버튼이 반복해서 비활성화되지 않도록 정리하고 입력 초점과 펼친 메뉴를 유지합니다. 실제 작업은 계속 한 번에 하나씩 처리하며, 기다린 요청은 실행 전에 계정·세션·권한과 요청 시간을 다시 확인합니다. 연결 리소스 96개는 기존 0.8.7 그대로이고 전송 실행부·드라이버·서버 코드를 이 버전에서 바꾸지 않습니다. 이전 패킷 손실 원인의 확정이나 게임 무중단 검증을 뜻하지 않습니다.

이전 0.8.6의 앱 안 공식 공지와 제휴 문의 안내도 유지합니다. 공지 조회는 계정 토큰·이메일·기기 식별자를 보내지 않으며 VPN 연결이나 앱 선택을 바꾸지 않습니다.

준비 순서
1. 사이트에서 이메일 인증과 비밀번호 설정
2. NEXT ZIP 전체 압축 해제 후 GreenchizNext.exe 실행
3. 사이트와 같은 계정으로 로그인하고 앱 추가 열기
4. 설치·실행 중인 앱 목록에서 여러 개 체크 → 선택한 앱 추가. 넥슨·글클메는 연결 파일 목록을 확인하고 확인한 파일 저장
5. 내 앱에서 사용할 앱 ON → 통합 VPN 켜기. 넥슨·메이플 전용 연결은 별도 안내에 따라 진행

환경에 따라 연결 품질과 호환성이 다를 수 있으며 게임 접속·지연 시간·제재 면제를 보장하지 않습니다. 그린치즈는 넥슨과 제휴하지 않은 독립 서비스입니다.
