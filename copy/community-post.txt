[서비스 운영자 안내] 글클메 정식 오픈을 준비하는 분께 그린치즈 VPN을 소개합니다.

넥슨 공식 FAQ의 Grand Launch 일정은 한국 시간 2026년 10월 22일(목) 오전 3시입니다. 변경 여부는 공식 공지를 확인해 주세요.

그린치즈는 Windows용 무료 VPN을 테스트 운영하고 있습니다. 현재 기본 다운로드는 게임·브라우저·런처 실행 파일을 선택하는 NEXT 0.8.9 Windows x64 시험판 ZIP입니다. 전체 압축 해제 후 GreenchizNext.exe를 실행합니다. 기존 0.1.38 파일은 이전 버전 링크로 별도 제공합니다.

0.8.9는 앱과 Windows 파일 정보의 버전 표시를 맞추고, 0.8.8의 승인 안내 창 정리를 유지합니다. 실제 연결 엔진은 0.8.7이며 관리자 연결 리소스 96개는 이전 배포본과 동일합니다. Chrome·Edge VPN 기능이나 클라이언트 연결·재시도 코드는 바꾸지 않았습니다.

서버 안정화 변경은 별도로 반영합니다. 회원 원장 WAL·읽기 분리와 개별 중계 소켓 오류의 영향 범위 분리를 포함하며, 일시적인 사용 중 응답은 기존 앱이 인식하는 방식으로 전달합니다. 서버 반영 후 기존 0.8.8 앱에도 같은 호환 방식이 적용되며, 권한 만료·철회 기준은 유지합니다. 고객 ZIP이 서버 변경을 설치하지는 않습니다.

임시 SQLite·메모리 전송에서 합성 회원 50명의 130.14초 갱신·인증된 데이터 왕복 시험을 완료했습니다. 실제 회원·외부 목적지 없이 수행한 시험으로, 실제 50대 PC나 장시간 게임 연결을 보장하는 결과는 아닙니다.

이전 0.8.6의 앱 안 공식 공지와 제휴 문의 안내도 유지합니다. 공지 조회는 계정 토큰·이메일·기기 식별자를 보내지 않으며 VPN 연결이나 앱 선택을 바꾸지 않습니다.

준비 순서
1. 사이트에서 이메일 인증과 비밀번호 설정
2. NEXT ZIP 전체 압축 해제 후 GreenchizNext.exe 실행
3. 사이트와 같은 계정으로 로그인하고 앱 추가 열기
4. 설치·실행 중인 앱 목록에서 여러 개 체크 → 선택한 앱 추가. 넥슨·글클메는 연결 파일 목록을 확인하고 확인한 파일 저장
5. 내 앱에서 사용할 앱 ON → 통합 VPN 켜기. 넥슨·메이플 전용 연결은 별도 안내에 따라 진행

환경에 따라 연결 품질과 호환성이 다를 수 있으며 게임 접속·지연 시간·제재 면제를 보장하지 않습니다. 그린치즈는 넥슨과 제휴하지 않은 독립 서비스입니다.
